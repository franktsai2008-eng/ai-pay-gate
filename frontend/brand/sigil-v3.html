What changed from v2: warmer wash, rounder corners, and the copy talks like a person (helpers, waiting on you, wants a word). The logo is now the word, set in Newsreader, with the S monogram in a tile for everything small. No invented symbol to explain. Blue is gone; sage green carries "agent" and "up", clay carries "needs you". The phone mockup still stands for mobile, but the brand lives on this desktop command center, like Harvey.

Type: Newsreader for the wordmark, headings and big numbers. Inter for everything else. Free Google font standing in for a licensed serif like Tiempos or GT Sectra if you want to buy one later.
